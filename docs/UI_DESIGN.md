# OrbitTLM Qt 中文界面 P0–P4 验收规范

## 总体布局

左侧按时间排列恢复的 KISS 业务包（不是以每个 223 字节帧充当一行业务遥测），右侧状态与详情，底部回放滑条、倍速、上一条、下一条。选择事件后所有业务页面以**当前事件以及之前已知信息**更新；不读取将来发生的状态。

## P0 — 中文总览 / 主事件流

- 记录时间范围显示“日志接收时间”，绝不当作星载 UTC。
- 去重帧数、业务识别数、未知包、SSDV 候选片段和分包统计来自实际会话。
- 未知类型显示“未识别业务包（F0 / 0F）”等；不附会公开子包。
- 电源 / 姿态 / 热控 / 载荷卡片只基于截至播放位置已识别的数据，缺失显示暂无，不补零。
- “日志报告 FEC 成功”“仅结构恢复”“应用 CRC 未校验”均为不同的状态信息。

## P1 — 分系统业务遥测

- 按源字段的中文名称与参数类别组织，带原始十六进制、位偏移与工程量公式。
- 可选字段时序图使用记录时间相对秒数；无真实时间时只用记录序号，且界面不隐瞒时间未知。
- 不支持的数据包保留原始记录，不强制解读。

## P2 — 姿态页

- 只选 SAT-S3 的“解算四元数 q0–q3”四个有定义的字段，按 public schema 的 int32 / 10000 换算。
- 仅在四元数四分量存在且数值有限时渲染相对方向。
- 不对四元数参考坐标系、分量语义或卫星天线极化绝对角作精度承诺。
- 导出 SAT-S3，实验性帧浮点候选导出保留但分开。

## P3 — 原始 / 调试

- “原始数据”页保留 KISS HEX 和分包列表。
- “调试信息”在工具菜单选择后打开，默认隐藏，不进入普通用户流程。
- 不去除开发者所需的帧级 MFC / VCID / 诊断信息。

## P4 — 图像数据

- 可指定 APID，扫描候选 SSDV 图像包、展示图像 ID / 包号 / 宽高。
- 展示观测的连续包序号覆盖率，**绝非图片真实总完成率**，总包数未确定必须说明。
- SSDV 由软件内置解码器重建 JPEG；缺失或 CRC 损坏的分片会计入诊断，解码器尽可能补齐缺失 MCU 并显示部分预览。

## 验收证据

Qt Widgets 构建与测试、中文默认页面可见性、调试页默认隐藏、双平台 CMake CI；界面布局最终还需使用 Windows DPI 100%、125%、150% 手动核对。
